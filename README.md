## 📁 프로젝트 구조

```
ubineeds.github.io/
├── 📄 index.html              # 메인 홈페이지 (동적 footer)
├── 📄 dev.html                # IT SW 개발 페이지 (동적 footer)
├── 📄 design.html             # 디자인 페이지 (동적 footer)
├── 📄 CNAME                   # 커스텀 도메인 설정 (ubineeds.com)
├── 📄 LICENSE                 # MIT 라이선스
├── 📄 README.md               # 프로젝트 문서
├── 📁 assets/
│   ├── 📁 css/                # 모듈화된 스타일시트
│   │   ├── common.css         # 공통 스타일 (CSS 변수, 기본 레이아웃)
│   │   ├── home.css          # 메인 페이지 전용 스타일
│   │   ├── dev.css           # 개발 페이지 전용 스타일
│   │   └── design.css        # 디자인 페이지 전용 스타일
│   └── 📁 js/                 # 모듈화된 JavaScript
│       ├── analytics.js       # GA4 이벤트 추적 시스템
│       ├── common.js          # 공통 기능 (테마, 네비게이션, 모바일 메뉴)
│       ├── footer.js          # Footer 동적 로딩 및 이벤트 관리
│       ├── home.js           # 메인 페이지 기능 (카운터, 애니메이션)
│       ├── dev.js            # 개발 페이지 기능
│       └── design.js         # 디자인 페이지 기능
└── 📁 components/
    └── footer.html           # 통합 Footer 컴포넌트 (스타일 포함)
```

## ✨ 주요 기능

### 🎨 사용자 경험
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 최적화
- **다크/라이트 모드**: 사용자 선호도에 따른 테마 전환
- **부드러운 애니메이션**: CSS3 애니메이션과 JavaScript 상호작용
- **접근성**: 키보드 네비게이션, 스크린 리더 지원

### 📊 분석 및 추적
- **실시간 사용자 분석**: GA4 기반 실시간 모니터링
- **이벤트 추적**: 사용자 행동 패턴 분석
- **전환율 측정**: 연락처 클릭, 서비스 관심도 추적
- **성능 모니터링**: 페이지 로딩 속도, 사용자 경험 지표

### 🔧 기술적 특징
- **모듈화 아키텍처**: 유지보수성과 확장성 고려
- **동적 컴포넌트**: Footer 동적 로딩으로 코드 중복 제거
- **성능 최적화**: 빠른 로딩 속도와 효율적인 리소스 관리
- **SEO 최적화**: 검색 엔진 친화적 구조
- **브라우저 호환성**: 주요 브라우저 지원
